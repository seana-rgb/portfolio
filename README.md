# Sean Amihan — Portfolio

A personal portfolio site built while learning web development with CodeSquad.

🔗 **Live site:** https://seana-rgb.github.io/portfolio

- A parallax desert-themed hero section
- Links to my [LinkedIn](https://www.linkedin.com/in/sean-amihan-1145753a3/) and [GitHub](https://github.com/seana-rgb)
- Screenshots from my CodeSquad Mini Course assignments, with a click-to-enlarge lightbox
- Places I'd like to go for a tech career, and why
- Tech roles I'm interested in exploring: Agentic Workflow Engineer, AI Automation Specialist, and AI Engineer

- HTML
- CSS (custom properties, clip-path, scroll-based parallax)
- JavaScript (DOM manipulation, event listeners)

## Running locally

Clone the repo and open `index.html` in your browser — no build step or dependencies needed.

\`\`\`
git clone https://github.com/seana-rgb/portfolio.git
cd portfolio
